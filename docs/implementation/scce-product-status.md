## Current direction

Language realization now uses evidence-owned exact spans and typed recursive construction algebra; the retired JOIN compiler, storage formats and runtime fallback are deleted. Full-DAG segmentation, adjacency statistics and source observations remain as cognitive witnesses rather than a second fragment-gluing model.
