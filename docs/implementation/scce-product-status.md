# SCCE implementation checkpoint

Updated November 10, 2026.

## Current direction

Preserve the complete engine while removing its separate language JOIN predictor. Language realization now uses evidence-owned exact spans and typed recursive construction algebra; the retired JOIN compiler, storage formats and runtime fallback are deleted. Full-DAG segmentation, adjacency statistics and source observations remain as cognitive witnesses rather than a second fragment-gluing model. GraphQL/Relay is the replacement application boundary, not a parallel brain. PostgreSQL remains the native durable store.

The active architecture refactor is specified in `meta-level-6-runtime-and-pack-refactor.md`: split the 7,272-line production turn into cohesive components and separate compact kernel state from exact corpus bytes and offline learning state without replacing SCCE's existing language, code, multilingual or translation paths. Any future independently distributable artifact must package those existing learned structures rather than introduce a second learning or realization model. Storage acceptance is qualified preservation of required signal and capabilities plus bounded write/read/memory cost; the resulting whole-product amplification is measured rather than used as a deletion rule.

The local tag `archive/20261110-before-graphql-relay` (`1f3bf822`) is historical only. It records an earlier replacement attempt whose full sweep regressed. The current implementation redoes the cutover against the restored baseline with explicit realization failures, evidence ownership, producer-side admission, registered GraphQL operations and focused regression controls; it does not restore the archived JOIN runtime.
