# Canonical public initial-prior export

The exporter records SCCE's existing public background corpus separately from the fresh public packets delivered identically to both systems. It does not feed the whole background corpus into Qwen's 32768-token context, equate it with Qwen's pretraining, generate benchmark cases, or certify factual, creative or coding competence. The default 48-cell factory still tests fresh synthetic factual sources. Whole retained-corpus factual QA requires separately preregistered coverage; neither this inventory nor the ten-document retained cloze diagnostic supplies it.

Wait for all intended source recompiles, publication and language-identity finalization to stabilize. Use the actual canonical configuration, including its `security.informationAccess`, rather than the default local database. This command only reads PostgreSQL. It makes no server, model, network-publication, ingestion or freeze request. Its local output must be outside the configured ingestion roots:

```powershell
node tools/blind-comparison/export-public-admission.mjs --config C:/Users/react/scce/.scce/brain-5gb-20261111-r004.json --all-public-current --out C:/Users/react/scce-comparison-public/r004-final
```

`--all-public-current` enumerates actual canonical source versions with promoted evidence or direct source-owned profiles. It excludes superseded versions and inaccessible/non-public source owners, explicitly counts non-public exclusions, and fails on inaccessible evidence/profile/model dependencies of a selected owner. A successful public inventory is not a claim that the private or source-independent pooled remainder of the brain was exported. Source-independent pooled profiles/models are outside this direct source-owned scope. The final experiment must separately disclose such initial priors and independently verify the whole brain's finalization.

Every exported record must satisfy the configured canonical read policy **and** have `exportClass: public` with no principal or compartment restrictions. Export does not declassify records. Existing public labels do not attest that the operator never ingested evaluation material: the operator must audit the declared sources and exclude benchmark factories, private grading, scores and future case revisions from every public ingestion root. No seed, private case, score or ballot is generated or copied by this command.

For a deliberate subset and explicit language/usage declarations, supply `--source-selection FILE` instead of `--all-public-current`. The selection format is:

```json
{"sources":[{"sourceVersionId":"SOURCE_VERSION_ID","contentHash":"sha256_64_HEX_DIGEST","usageClass":"factual_source","naturalLanguage":"en"}]}
```

Actual IDs and hashes must come from the operator's canonical source inventory. The hash is mandatory, and missing, stale, denied or changed selections fail. Optional `formalLanguage` declares a source language; a declaration unions coverage and never proves competence. Unknown locales remain undeclared. No script-to-locale conversion occurs. `usageClass` is metadata only: use `factual_source`, `code_prior`, `language_prior`, or `lexical_language_prior` as appropriate. Canonical `sourceKind: lexical_knowledge` is automatically marked `lexical_language_prior`; other undeclared source kinds stay `unclassified_background`. XML, CoNLL-U, lexical and language-prior artifacts are never automatically routed into factual case generation or reference context.

The exporter writes content-addressed exact binary source files, `sources.jsonl`, a paged metadata index containing promoted evidence/direct profile/ngram IDs and source hashes, and `admitted-public-manifest.json`. It uses the existing canonical blob/range/archive reader. Archive verification-cache updates remain ephemeral; the PostgreSQL connection is `REPEATABLE READ READ ONLY`. A second fresh read transaction must reproduce the same selected metadata digest before a complete manifest is published. Source/evidence/profile/model metadata drift fails. This is an observation over two snapshots, not a lock against later changes, a current compiler-recipe certification, or a substitute for finalization.

Source reads are sequential. Defaults allow at most 128 MiB per decoded source **or range parent**, 1 GiB of unique exported source bytes, 256 MiB of streamed metadata, 100000 source owners and 128 rows per metadata page. They can be reduced with `--max-item-bytes`, `--max-total-bytes`, `--max-metadata-bytes`, and `--page-rows`. No corpus-body array is constructed. These are exporter bounds, not OS RAM quotas. A larger parent is rejected before the canonical reader materializes it. The canonical archive reader's own bounded descriptor/parent caches remain in effect.

Rerun the same command and output path to resume. Existing source files are reused only after their size and full SHA-256 match current canonical ownership; changed or partial files are rewritten and rehashed. Metadata is regenerated and rechecked. Starting a new export removes the earlier complete manifest, so failure cannot leave a stale certificate. `.export.lock` prevents concurrent exporters targeting the same directory. Remove a stale lock only after proving its owning exporter is dead. Completed exports are local artifacts; review their scope, labels, hashes and source provenance before sharing them.

After that review and final brain stabilization:

```powershell
node tools/blind-comparison/campaign.mjs prepare --config C:/Users/react/scce/.scce/brain-5gb-20261111-r004.json --admitted-public-manifest C:/Users/react/scce-comparison-public/r004-final/admitted-public-manifest.json --out .scce/verification/r004-qwen-final --threads 4 --device cpu --context-tokens 32768 --output-tokens 4096 --max-reference-model-bytes 4000000000
```

Preparation performs reference admission/inference and freezes artifacts; run it only after the shared refresh work and RAM use finish. New-schema manifests are fully rehashed and every referenced source/index artifact is frozen with role `preparation`, separate from the protocol's shared per-case corpus-access declaration. Legacy admitted manifests keep their existing behavior. The reference still receives only each complete ordered public case packet, with no-truncation admission and per-answer context accounting. The pinned public inventory is an experiment declaration; it does not claim that either answer process consumed every corpus byte or that the reference was given outside-workspace background-file tools. Default cells, thresholds, judges and private checks are unchanged.

For process measurements, copy `process-policy.example.json` to an ignored local file and replace the illustrative service PIDs with the actual highest intended parent processes. Preparation resolves their current birth identities. The example uses the operator's decimal 7 GB **sampled process-RSS ceiling**, `7000000000`, separately for each system's observed adapter/declared daemon trees. Keep `rssBudgetBytes: null` if only observing. A sampled excess fails the answer child; it does not kill a declared daemon or enforce a hard OS/native/product RAM quota. Total product RAM remains unknown; RSS may double-count shared pages, shared services may do other work, and GPU/cache/driver allocations are not included. Threads and native tool elapsed/output limits are requested/observed controls, not exclusive CPU or network isolation. No external containment attestation is invented. See [PROCESS-RESOURCES.md](PROCESS-RESOURCES.md). Independent human ballots and any independent custody/resource attestations still come from actual external reviewers/providers.
